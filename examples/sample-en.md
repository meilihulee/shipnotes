## v1.4.0

### New
- Added a keyboard shortcut to duplicate a block. (#212)
- You can now export a page as a PDF file. (#219)

### Improved
- Debounced queries, results appear 2x faster.
- Improved the error message when an invite link has expired.
- **Breaking:** Removed support for Safari 15.

### Fixed
- Fixed an issue where images were missing their alt text.
- Fixed potential data loss during offline editing.
- Fixed the dark mode toggle not being saved after reload.

**What's new:** v1.4.0 is out. This release includes a keyboard shortcut to duplicate blocks, the ability to export pages as PDFs, fixed missing alt text on images, improved offline editing, and a saved dark mode toggle.
