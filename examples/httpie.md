### New

### Improved
- Improved the SSL context creation process by explicitly loading default certificates. ([#1596](https://github.com/httpie/cli/pull/1596))
- Improved the JSON data structure for the example. ([#1606](https://github.com/httpie/cli/pull/1606))

### Fixed

**What's new:** httpie cli 3.2.4 is out. This release brings some improvements! We’ve added an alias for HTTPS in fish completions, fixed a broken link to CurliPie, refined the SSL context creation process with explicit certificate loading, and enhanced the JSON data structure for example usage.
